# Документація до проєкту

## Інформація про репозиторій

Цей репозиторій створено для виконання лабораторних робіт з дисципліни, пов’язаної з розробкою програмного забезпечення та роботою з системою контролю версій Git.

## Лабораторна робота №6

У межах лабораторної роботи №6 було створено папку `lab6`, у якій розміщено документацію до проєкту.

## Мета роботи

Метою роботи є створення документації до проєкту та налаштування її відображення за допомогою GitHub Pages.

## Структура проєкту

У репозиторії створено папку `lab6`. Усередині неї знаходиться папка `docs`, яка містить файл `index.md`.

## GitHub Pages

Документація проєкту буде опублікована за допомогою GitHub Pages.
